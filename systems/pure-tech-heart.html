纯粹的技术心灵，与一双等着接住它的手

搞技术的人，或者说他妈的理工男，心很纯粹（只是工程伦理上的，其他则不是），总认为这个东西很炫酷，它就可以按我设想的方式改变世界，让自己立身立言（呕）。这就很有趣了，导致一个什么情况呢？每年毕业季节，荒坂集团们看见这么多纯粹的技术心灵、学术心灵，可开心了。

一、什么是纯粹

这段话很粗鲁，但戳到了一个真东西。搞技术的人确实有一种独特的纯粹。这种纯粹不是道德上的善，不是雷锋式的无私，而是另一种东西：一个系统如果逻辑自洽，一个算法如果精妙优雅，一个架构如果干净，它本身就是值得做的。不需要外部理由。你问他这个产品对社会的影响是什么，他会说"它是去中心化的"。你再问去中心化对普通人意味着什么，他会说"它没有单点故障"。你再问一次，他会说"你再看看这张架构图"。他不是在回避，他是真的觉得架构图就是答案。工程伦理管的是他手里的东西牢不牢、会不会崩、是不是把 corner case 都覆盖了；至于这个东西被放出去之后会变成什么，那是另一个问题，他不太问，也不太会问。

更妙的是那种"改变世界"的冲动。一个学计算机的本科生在宿舍里写了一个小 demo，凌晨三点跑通了，屏幕上的数据正确了，那个瞬间他发现自己是造物主——他从虚空里召出了一个运行着的系统，这个东西以前不存在，现在因为它而存在的。这种感觉极其迷人。它跟做物理实验不一样，物理实验是发现已经在那里的规律，你只能谦卑地走过去。写程序是创造，是你定义了规则，系统服从你。你当然会想：如果我把这个东西做出来，让几百万人用，世界就会按我希望的方式变得更好。并且在这个过程中，我的名字会被记住，我的能力被验证，我立了身，也立了言。这里面没有任何算计，是一种近乎纯真的、孩子气的东西。他从小就被夸聪明，现在他终于能做一件事来证明这种聪明是有价值的，是可以被世界看见的。他渴望被看见，但他不承认。

二、但纯粹不等于是正确的

问题在于，这种纯粹只覆盖了工程活动的一小段——从想法到 working software 的这段，技术性的这段。而现实世界里一个产品从代码变成社会事实，中间要穿过好几层东西。第一层，商业。你这个东西怎么赚钱？不是怎么"创造价值"，是怎么从用户身上把钱收上来。广告、订阅、数据买卖、平台抽成、把用户变成产品。你做的那个优雅的去中心化协议，最后可能被套了一层壳，里面跑的还是个广告推荐引擎。你技术上的干净，在商业层可以被包进任何东西里。第二层，组织。一个公司里你的代码会不会被合并，不是你代码写得最好决定的，是你的老板站哪边，你的团队有没有话语权，你的产品的 GMV 报表好不好看。你在大学里靠做题得分，到了公司里靠的是站队、立项、汇报、抢资源、甩锅、借势。技术能力在这里只是入场券，进门之后打的是另一种游戏。第三层，社会后果。你花了两年优化了一个推荐算法，让用户的平均使用时长提升了 15%。你很骄傲，因为技术指标非常漂亮。但使用时长从哪里来的？凌晨两点还在刷视频的人的时间、注意力、睡眠。你创造的是价值还是剩余？这其实是一个很重的问题，但工程的训练从来不教你怎么问。它只问你有没有把延迟压到 200ms 以下。

这就像你是一个造桥匠人，你一生追求的是把石拱桥造得极薄、极轻、极美，你所有的心血都在那条弧线上。然后有人把你的桥搬走，架在一条护城河上，用来把城里的人围起来收通行费。你说，这不是我的本意。对方说，但你造的桥真的很好用，一压不垮，我们明年还要六座。这就是工程技术遇到商业组织后发生的典型故事。你的纯粹没有错，你的优雅没有错，你造的桥确实是好桥。但桥一旦离开你的手，它就属于建在什么地方、被谁使用、为了什么目的这些更大的问题了。而你被训练成只对桥的结构负责，不对桥的用途负责。这个训练成果在毕业季显现得特别清晰：一大批准毕业生，技能一流，心思单纯，渴望被认可，渴望做大事，但在"我做的东西最终会变成谁的权力"这个问题上，他们诚实地说，没怎么想过。

三、荒坂为什么开心

为什么荒坂集团们喜欢这群人？答案太简单了，简单到说出来让人觉得残酷：因为他们是世界上性价比最高的燃烧材料。你给一个年轻人一笔在他二十岁看来很多的钱，比如五十万年薪加期权，他就觉得已经抵达了。他不会算账。他不知道自己的产出价值多少。他不知道期权稀释后的真实价格。他只知道"我终于被选中了"，这种被选中的感觉本身就是重要的报酬。然后他会极其勤奋地工作。不是因为被逼的，是他自己愿意。因为他在做"很酷的事"，同事都是聪明人，每天都有技术挑战，代码行行都在改变世界。他甚至觉得加班是一种特权，因为不加班的人不配参与这么重要的工程。这个过程通常会持续三到五年。然后他开始感觉到一些不对。不是具体的某件事不对，而是一种越来越明显的错位感：他的同事们逐渐少了，那些聪明人要么升上去做了管理，开始玩他看不懂的权力游戏；要么离开了，去创业，去自由职业，去留学。替代他们的是一批新的、更年轻的、同样纯粹的毕业生。而他发现自己坐在一个奇怪的中间位置上——技术上他还是最强的，但这个组织给最强技术的定价就是最强的，它不会因为你技术最强而让你做决策。决策是另一些人做的，那些人的核心能力不是技术。他当初以为技术就是权力的那个故事，在毕业第四五年左右，第一次出现裂缝。

更深一层来看，荒坂不只是想要你的劳动力。现代大型科技公司最厉害的地方，是它消费的是你的纯粹本身。你的那种"这个东西很酷"的热情，那种"我凭本事立足"的自尊，那种"我在参与历史"的意义感——这些都是不可替代的高质量燃料。一个纯粹的技术心灵在凌晨三点 debug 时不会偷懒。不是因为有人在看着，是那个 bug 本身在侮辱他的智力。他一定要修掉它。这种驱动力是内部的，不需要管理层挥鞭子。荒坂的 HR 和管理架构花了很大功夫去保护和喂养这种内驱力。给你 free food，给你灵活的上班时间，给你看起来扁平的组织结构，给你听起来很厉害的 title，给你在技术博客上写文章的机会，给你内部的黑客马拉松让你再做一次造物主。这一切的目的不是剥削你的劳力——劳力到处都有，外包出去更便宜——它的目的是占有你的内驱力，你的造物冲动，你的那种"我在创造未来"的幻觉。因为这种燃料烧出来的东西质量不一样，外包永远写不出那种倾注了自我证明欲望的代码。

四、立身立言，还是被编入他人的叙事

"让自己立身立言"——这其实是一句中国古代士大夫的理想。从前是用来给文人用的。现在用来给工程师用，很微妙。一个士大夫立言，立的是经世济民之学，立好了可以影响帝王。一个工程师立言，立的是一套在某个公司私有仓库里跑了两年的微服务，外界看不见，同行不知道，离职之后代码还在那里继续跑，但上面已经没有你的名字，因为它本来就没有名字，它是一段代码，你写在公司的时间、用公司的设备、为了公司的业务，物权完全不属于你。你"立"的那个东西，其实从来就没在你的名下站过。你说不对，我可以写博客，我可以做开源，我可以去会议上演讲。是，你可以。而且公司很鼓励你这样，因为这等于你在用你的个人品牌给公司背书。你很认真地准备了一个技术分享，把架构图画得漂漂亮亮，在台上讲了一个小时。台下有人鼓掌。你觉得这就是立言了。但几年后回头看你会发现，你所有的技术洞见都来自于你在公司内部做的那些产品——你对行业的理解被你的雇主定义，你解决过的最难的问题都是雇主给你的问题。你没在这个雇主之外发现过问题。你的问题意识是被分配的。你真能自己立得住，还是被立在一个更大的叙事里，而你以为那是你自己的声音？

还有一个更残酷的事情，就是年龄。纯粹的技术心灵有一个天然的使用期限。不是技术过时了——真正好的工程师一直在学。是当你的纯粹开始变复杂之后，你对荒坂的价值就下降了。三十岁前后，一个工程师通常会发生一些变化。你开始想：我做的事情的意义是什么？我是不是在把桥卖给收护城河通行费的人？我能不能选择不造这座桥？你开始要求参与决策，要求知道产品方向，要求对用户的影响有发言权。你开始变得没有那么"好用"了。与此同时，又有一批二十二岁的、纯粹的、充满热情的、不加怀疑的毕业生来了。他看着 DL 框架和 LLM 论文的眼神跟你当年一模一样。荒坂开心地把接力棒递给了他。这个循环已经转了很多年，还会继续转下去。

五、那么怎么办

还是多说一句，这事不能全部怪荒坂。荒坂不是反派，它不是阴谋，它是一个有内在逻辑的系统。资本要找增长，增长要找人才，人才要找意义，意义最容易挂在"又在做很酷的事"上。整个链条里每一环都是自愿的。没有坏人的系统最难对抗。你没办法辞职，因为下一家公司也是这个结构。你也没办法回去做纯学术，因为学术圈的资源政治一点不比公司少。你没办法不工作，因为你要生活。这不是给建议。不是喊口号说"保持清醒"或者"不要被异化"——这些话太轻了，轻到跟没说一样。你如果能保持清醒就不会来阅读这篇文章了。你来，是因为你已经感觉到了什么不对。你只是说不清那是什么。我能做的是帮你把那个"感觉不对"的东西先变成一些有形状的想法，然后你再自己决定怎么办。真正的决策总是你自己的，因为你要在那个具体的处境里吃饭、租房、养家、面对父母和同学的目光。没有人可以替你承担"不去荒坂"的代价，也没有人应该替你承担。所以拒绝也好，参与也好，半参与也好，都不是对错问题，是你自己的权衡。

但也许有一条路是值得认真考虑的：不要让你的技术人生只有一个主人。如果你所有的问题都是雇主给的，你所有的成就感都来自雇主的季度目标，你所有的技能组合都被雇主的业务需求塑形，那么你就是被彻底绑定在了单一叙事里。你可以试着做一点点"出逃"：在自己的时间里做一个小项目，跟工作完全无关；去给一个开源项目贡献一点代码，哪怕只是修一个文档里的 typo；写一个技术博客，讲的不是你公司产品的架构，而是你在周末用树莓派和传感器做的那个气象站。这些东西很小，单独看没什么用。但它们在做一个很重要的事：提醒你，你的技术能力不需要经过荒坂的批准才存在。你对技术的热爱，可以不通过雇主的"战略方向"来表达。你的好奇心可以自己选择方向。这不叫反抗，这叫给自己留一块自留地。在这块地上，你是你自己的主人。你做的东西可能笨拙，可能没用，可能永远不会被几百万用户使用，但它至少是你自己决定要做的。就够了。

二、纯粹不等于是正确

三、荒坂为什么开心

为什么荒坂集团们喜欢这群人？答案太简单了：因为他们是世界上性价比最高的耗材, 人矿。你给一个年轻人一个package, 一份在他二十岁看来很多的钱，比如200万年薪加期权，他就觉得:啊!我的人生已经到达了,我终于做题做过所有人了。他不知道自己的产出价值多少。他不知道期权稀释后的真实价格。他只知道"我终于被选中了"，这种被选中的感觉本身, 对理工人就是一种reward。然后他会极其勤奋地工作。不是因为被逼的，是他自己愿意。因为他在做"很酷的事"，同事都是聪明人，每天都有技术挑战，代码行行都在改变世界。他甚至觉得加班是一种特权，因为不加班的人不配参与这么重要的工程。这个过程通常会持续三到五年。然后他开始感觉到一些不对。不是具体的某件事不对，而是一种越来越明显的错位感：他的同事们逐渐少了，那些聪明人要么升上去做了管理，开始玩他看不懂的权力游戏；要么离开了，去创业，去自由职业，去留学。替代他们的是一批新的、更年轻的、同样纯粹的毕业生。而他发现自己坐在一个奇怪的中间位置上——技术上他还是最强的，但这个组织给最强技术的定价就是最强的，它不会因为你技术最强而让你做决策。决策是另一些人做的，那些人的核心能力不是技术。他当初以为技术就是权力的那个故事，在毕业第四五年左右，第一次出现裂缝。当然也可能没到那时候他就猝死了.

更深一层来看，荒坂不只是想要你的劳动力。现代大型科技公司最厉害的地方，是它消费的是你的纯粹本身。你的那种"这个东西很酷"的热情，那种"我凭本事立足"的自尊，那种"我在参与历史"的意义感——这些都是不可替代的高质量燃料。一个纯粹的技术心灵在凌晨三点 debug 时不会偷懒。不是因为有人在看着，是那个 bug 本身在侮辱他的智力。他一定要修掉它。这种驱动力是内部的，不需要管理层挥鞭子。荒坂的 HR 和管理架构花了很大功夫去保护和喂养这种内驱力。给你 free dogfood，给你灵活的上班时间，给你看起来扁平的组织结构，给你听起来很厉害的 title，给你在技术博客上写文章的机会，给你内部的黑客马拉松让你体验当造物主的快感。这一切的目的不是剥削你的劳力——劳力到处都有，外包出去更便宜——它的目的是占有你的内驱力，你的造物冲动，你的那种"我在创造未来"的幻觉。因为这种燃料烧出来的东西质量不一样，外包永远写不出那种倾注了自我证明欲望的代码。

四、真的立身立言了吗? 还是被编入了他人的叙事?

"立身立言"——一句中国古代士大夫的理想。从前是用来给文人用的。现在用来给他妈的我们中国这么多被蒙骗迫害的理工科学生/工程师用, 一点问题都没有。一个士大夫立言，立的是经世济民之学，立好了可以影响帝王。一个工程师立言，立的是一套在某个公司私有仓库里跑了两年的"开源"工具. 外界看不见，同行不知道，离职之后代码还在那里继续跑，但上面已经没有你的名字，因为它本来就没有名字，它是一段代码，你写在公司的时间、用公司的设备、为了公司的业务，物权完全不属于你。你"立"的那个东西，其实从来就没在你的名下过。你说: 不对啊，我可以写博客，我可以做开源，我可以去会议上演讲。是，你可以。而且公司很鼓励你这样，因为这等于你在用你的个人品牌给公司背书。你很认真地准备了一个技术分享，把架构图画得漂漂亮亮，在台上讲了一个小时。台下有人鼓掌。你觉得这就是立言了。但几年后回头看你会发现，你所有的技术洞见都来自于你在公司内部做的那些产品——你对行业的理解被你的雇主定义，你解决过的最难的问题都是雇主给你的问题。你没在这个雇主之外发现过问题。你的问题意识是被分配的。你真能自己立得住吗? 倒不如说你被砌在一个更大的叙事里，被大厂夺舍, 成为他们的肉喇叭, 而你以为那是你自己的声音.

还有一个更残酷的事情，就是年龄。纯粹的技术心灵有一个天然的使用期限。不是技术过时了——真正好的工程师一直在学。是当你的纯粹开始变复杂之后，你对荒坂的价值就下降了。三十岁前后，一个工程师通常会发生一些变化。你开始想：我做的事情的意义是什么？我是不是在把桥卖给收护城河通行费的人？我能不能选择不造这座桥？你开始要求参与决策，要求知道产品方向，要求对用户的影响有发言权。你开始变得没有那么"好用"了。与此同时，又有一批二十二岁的、纯粹的、充满热情的、不加怀疑的毕业生来了。他看着 DL 框架和 Agent 论文的眼神跟你当年一模一样。荒坂开心地把接力棒从你手中递给了他。这个循环已经转了很多年，还会继续转下去。

五、那么怎么办

这事主要怪荒坂集团, 但也不能全部怪荒坂。荒坂是反派，也是一个有内在逻辑的系统。资本找增长，增长找人才，人才找意义，意义最容易挂在"做很酷的事"上。整个链条里每一环都是自愿的。没有坏人的系统最难对抗。你辞职也没用，因为下一家公司也是这个结构。你幻想做纯学术也没用，因为学术圈的这种利用一点不比公司少。你没法不工作，因为你要生活。

你如果能想清白, 就不会读到这里行字了。你来，一定是因为你已经感觉到了什么不对。你只是说不清那是什么。我能做的是帮你把那个"感觉不对"的东西, 变成一些有形状的想法，然后你再自己决定怎么办。真正的决策总是你自己的，因为你要在那个具体的处境里吃饭、租房、养家、面对父母和同学的目光。没有人可以替你承担"不去荒坂"的代价，也没有人应该替你承担。所以拒绝也好，参与也好，半参与也好，都值得我的尊敬。

但也许有一条路是值得认真考虑的：不要让你的技术人生只有一个主人。如果你所有的问题都是雇主给的，你所有的成就感都来自雇主的季度目标，你所有的技能组合都被雇主的业务需求塑形，那么你就是被彻底绑定在了单一叙事里。你的技术能力不需要经过荒坂的批准才存在。你对技术的热爱，可以不通过雇主/板块热点/学术热点的"战略方向"来表达。你的好奇心可以自己选择方向。这不叫反抗，这叫给自己留一块自留地。在这块地上，你是你自己的主人。你做的东西可能笨拙，可能没用，可能永远不会被几百万用户使用，但它至少是你自己决定要做的。就够了。
